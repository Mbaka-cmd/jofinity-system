# Jofinitycore Systems Ltd

Company website for Jofinitycore Systems Ltd — a Kenyan security systems
provider offering CCTV installation, access control, electric fencing,
alarm systems, biometric systems, and networking solutions.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `projects.html` — Projects
- `contact.html` — Contact

## Tech Stack
- HTML5, CSS3, vanilla JavaScript
- Node.js (`server.js`) for backend/contact form handling
- Font Awesome icons

## Structure
- `css/style.css` — all site styling
- `js/main.js` — hero slideshow, nav behavior, scroll animations, counters, contact form, project filters
- `images/` — site imagery and client logos
- `admin.js`, `contact.js` — backend handlers
